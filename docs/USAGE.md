# PobTools 功能使用說明

**繁體中文** | [English](USAGE.en.md)

本文說明 PobTools 各功能的操作方式。第一次安裝請先看
[安裝教學 INSTALL.md](INSTALL.md)。

---

## 一、啟動器

雙擊 `pob-zh.exe` 開啟啟動器。啟動器會自動偵測放在同一層的 POB 資料夾:

- 每個偵測到的遊戲版本會列成一列,顯示 POB 版本號與**啟動**按鈕。
- 上方工具列有翻譯編輯器、過濾器編輯器、輿圖策略、軍團珠寶計算器、
  搜尋字串產生器的入口。
- 工具以獨立視窗開啟(v0.5.0 起),啟動器保持開啟,可同時使用多個工具。
- 底部狀態列可切換**介面語言**(繁中 / 簡中 / English)與**字型**。

### 切換語言

底部語言下拉可即時切換啟動器與 POB 介面語言。翻譯資料需對應語系存在
(預設提供 `zh-rTW` 繁體與 `zh-rCN` 簡體)。

### 切換字型

底部字型下拉會列出 `Fonts\` 資料夾內所有 `.ttf`。想加入自己的字型,把 `.ttf`
放進 `Fonts\` 再重開啟動器即可(建議用 TrueType 靜態字型;可變字型需先 instance
成單一字重)。預設為 Noto Sans TC(OFL 授權)。

### 調整字體大小與視窗大小

這兩項只影響啟動器與它的工具視窗,POB 本身不受影響(v1.3.0 起):

- **字體大小**:設定頁「介面」區的滑桿,14–26 px,預設 19。整個啟動器介面
  (文字、按鈕、間距)會一起放大縮小,拖曳放開後立即生效;獨立視窗開啟的
  工具(過濾器編輯器、輿圖策略等)下次開啟時套用同一個大小。「恢復預設」
  回到 19 px。
- **視窗大小**:啟動器視窗可以直接拖曳邊緣調整,放開後的大小會自動記住;
  也可在設定頁「介面」區直接輸入寬 x 高。「各自獨立的視窗」與「在啟動器裡
  開成分頁」兩種模式各自記一組大小,互不影響。「恢復預設」回到該模式的預設
  尺寸(獨立 1000x700、分頁 1500x950,依螢幕縮放比例放大)。

### 外觀分頁(POB 視窗的外觀)

啟動器的「外觀」分頁管 POB 視窗長什麼樣,**PoE1 與 PoE2 各自一組設定**(頁面
最上方「套用到」切換);改動會即時套用到該遊戲已開啟的 POB 視窗,新開的直接
套用。全部只在 Windows 出現。

#### POB 面板不透明度

0%–100%,預設 100%(不透明,等於關閉)。這一項影響的是 **POB 視窗本身**,不是
啟動器;視窗**不會透出桌面**:

- 淡出的是 POB 的**外框**:側欄(含屬性清單框)的底色、上方工具列、天賦頁底部
  工具列與它們之間的分隔線;0% 時這些完全消失,只剩文字、圖示與控制項。文字、
  圖示、按鈕、下拉選單、tooltip 與彈出視窗都維持不透明。
- 外框底下是固定的最底層:在天賦頁,天賦樹畫布會延伸到整個視窗,側欄與工具列
  疊在樹上;其他分頁則是原本的斜紋底。樹在側欄下方的部分只能看、不能點,
  滑鼠在側欄上時仍是操作側欄。
- 拖動時已開啟的 POB 視窗會即時跟著變,放開後才寫入設定;新開的 POB 視窗
  直接套用。兩種視窗模式都適用。
- 僅 Windows 支援;macOS/CrossOver 下不顯示這個選項。

#### 背景圖片與霧面(毛玻璃)

同一分頁的另外四個設定,同樣分遊戲儲存、全部即時生效:

- **背景圖片**:把 PNG/JPG/WebP 放進 `PobTools\Backgrounds\`(「開啟資料夾」會
  直接開到那裡,放好按「重新整理」),下拉選它。圖片會鋪滿整個 POB 視窗當最底層
  (依比例裁切、不隨天賦樹移動),天賦樹與各分頁畫在它上面;選「預設」回到 POB
  內建的斜紋底。這個資料夾不會被更新覆蓋。
- **背景亮度**:圖片壓暗的程度,預設 50%,避免蓋過節點與文字。
- **霧面強度**:把側欄、上方工具列、天賦頁底部工具列變成毛玻璃——面板底下的畫面
  先模糊,再蓋上面板的淡色(濃度就是上面的「面板不透明度」)。0% 不模糊;
  搭配面板不透明度 0–30% 效果最像液態玻璃。
- **天賦樹底圖**:節點底下那層深色底紋的不透明度,預設 100%(與原版相同)。調低
  就能在天賦頁也看到背景圖片;0% 完全不畫,節點直接落在背景圖上。

### 自動更新

啟動器每天會在背景檢查一次 GitHub 上的新版本(v0.3.0 起):

- **翻譯資料更新**(修訂版,例如 0.3.0 → 0.3.1):自動下載並套用,右上角
  短暫顯示「翻譯資料已更新」,不需要任何操作;POB 下次啟動生效。
- **主體更新**(例如 0.3.x → 0.4.0):右上角出現橘色「發現新版」按鈕,
  點擊後自動下載、替換並重新啟動。更新前的舊檔會暫存為 `.old`,
  下次啟動自動清除;更新過程任何一步失敗都會還原回原版本。
- 你的個人設定(`pob-zh.ini`、`PobTools\` 資料夾)與 POB 本體資料夾
  完全不會被更新動到。

**不想每次都按那個按鈕**:設定頁「程式更新」勾選「啟動後自動安裝新版本」
(v1.4.0 起,預設關閉)。勾了之後 PobTools 一開啟就檢查,有新版本直接裝好並
重新開啟。它只在**剛啟動、你還沒開過 POB 或任何工具**的時候動手;有 POB 在跑
時一律不動(那會動到 POB 正在用的檔案)。你正在使用途中才發現的新版本,仍然是
右上角那個按鈕等你按。

進階:也可以在命令列執行 `pob-zh.exe --app-update-check`(只檢查)或
`pob-zh.exe --app-update`(檢查並更新,不自動重啟)。

> **連不上 GitHub 的網路環境**(例如需要代理的地區):設定頁「網路」區可填
> HTTP 代理(如 `127.0.0.1:7890`);留空則自動跟隨系統代理,開著 Clash / V2Ray
> 類工具的系統代理即可直接使用。更新檢查、翻譯資料與圖示下載都會經過該代理。

### POB 內的中文搜尋

v0.5.0 起,POB 物品頁的傳奇/基底資料庫搜尋框可以**直接輸入中文名稱**
查詢物品(輸入英文照常可搜)。此功能在載入時以記憶體層修補實現,
POB 檔案不會被修改;若未來 POB 改版導致修補點消失,會自動退回
英文搜尋,不影響其他功能。

## 二、翻譯編輯器

用於檢視與修改繁中字典。適合修正個別錯譯或補充新詞。

- 以英文原文搜尋條目,直接編輯對應繁中譯文。
- 儲存後即寫回 `Data\<game>\<locale>\*.json`,下次啟動 POB 生效。
- 字典是純 JSON,進階使用者也可直接編輯檔案。

---

## 三、過濾器編輯器

繁中化的物品過濾器(item filter)編輯工具,採三欄式區塊(block)編輯:

- **左欄**:過濾器內所有規則區塊清單。
- **中欄**:選中區塊的卡片檢視,顯示條件(物品類別、稀有度、階級等)與樣式
  (顏色、邊框、音效、minimap icon)。物品類別與詞彙以繁中顯示,並帶對應圖示。
- **右欄**:新增條件/樣式。
- **音效管理**分頁:管理過濾器使用的提示音效。

編輯完成後輸出仍是標準 `.filter` 檔(顯示層中文化,輸出保持遊戲可讀的英文),
可直接放進遊戲的 filter 目錄使用。

## 四、輿圖策略(Atlas Strategy)

規劃地圖天賦樹(Atlas passive tree)。可從啟動器工具列開啟,或用
`pob-zh.exe --atlas` 直接開啟。

### 基本操作

- **平移**:滑鼠拖曳畫布;**縮放**:滾輪。
- **配點**:點擊節點配點/取消,系統會自動計算從起點到目標的最短路徑(BFS)。
- 節點名稱與統計以繁中顯示(可用 F2 或按鈕切回英文對照)。

### 側欄統計

右側面板即時聚合目前配點的加成:

- 頂部顯示已用天賦點數與進度條。
- 搜尋框可用中英關鍵字過濾統計與節點清單。
- 點擊清單中的節點會**滑行聚焦**到該節點並標示金環。

### 多方案與分享

- 可建立多個配點方案(build),用下拉切換與增刪。
- **匯出**成 json 檔,或產生**分享碼**(`PTAT1|...`);他人可用匯入檔或貼上分享碼還原。

### 新賽季自動更新

工具列的更新按鈕(或 `pob-zh.exe --atlas-update`)會檢查 GitHub 上的最新圖譜資料,
一鍵下載並熱重載新賽季的天賦樹與圖集。繁中對照若尚未跟上,新節點會先顯示英文,
下次檢查時自動補上。

---

## 五、軍團珠寶計算器

計算永恆軍團珠寶(Timeless Jewel)各種子對天賦節點的改動:

- 選擇珠寶類型與陣營,輸入種子或條件搜尋,列出符合的節點變化。
- 節點與詞綴以繁中顯示,**搜尋框支援中文關鍵字**。
- 可直接產生交易站搜尋連結(支援國際服與台服)。

---

## 六、搜尋字串產生器

產生遊戲內搜尋框可用的正規表示式(regex),類似 poe.re:

- 先選遊戲(POE1 / POE2),再選物品清單;勾選想比對的詞綴後,
  上方即時組出搜尋字串,一鍵複製貼進遊戲內的搜尋框。
- POE2 提供換界石、碑牌、聖物、探險遺物清單。
- 常用組合可存成**書籤**(依遊戲分開保存)。
- 產生的片段除了避開清單裡其他詞綴的文字,也會避開遊戲搜尋列同樣會比對、
  但沒印在詞綴行上的文字:詞綴名稱、階層、標籤、提示說明、物品名與每張物品
  都有的固定行(v1.3.0 起)。把滑鼠移到清單項目上可以看到這些文字。

## 七、更新翻譯資料

### 一般使用者

通常不用做任何事:翻譯資料是獨立的一條發佈線(`data-1`、`data-2`…),程式會自己
檢查並更新。設定頁最下面會顯示目前的翻譯資料版本。

要手動換的話,到 Releases 找標著 `data-<編號>` 的那一則,下載
`PobTools-Data-<編號>.zip`,把裡面的 `Data` 資料夾覆蓋到安裝目錄 —— 包含
`Data\translations_version.json`,那是版本戳記,少了它程式會以為自己還沒更新過。

自己在改翻譯的人:設定頁「自動更新翻譯資料」選「否」,更新就不會覆蓋你的字典
(程式本身照樣更新)。有新翻譯資料時仍會通知,可按「立即套用一次」單次取用。

## 八、POB 或 PobTools 卡住的時候

設定頁最下面的「開啟問題紀錄資料夾」會開到 `PobTools\logs\`。程式遇到問題時會
把原因寫進這裡,一切正常的話它是空的。

從 v1.4.0 起,**卡住與當掉也會留下原因**:

- **沒有回應**:POB 或啟動器的畫面停住超過 20 秒時,會產生一個
  `hang-<日期>-<時間>-<角色>.txt`,裡面寫著當時正在做什麼(例如載入翻譯字典、
  執行 POB 的某個模組)以及各執行緒停在哪裡。同時 `error-<日期>.log` 會多一行摘要。
- **當掉**:程式意外結束時同樣會留下 `crash-<日期>-<時間>-<角色>.txt`。
- POB 沒有回應時,啟動器上方會出現一行提示,告訴你原因已經記下來了;POB 恢復或
  關掉之後那行會自己消失。**啟動器不會替你結束 POB** —— 有時候它只是在算一個很
  慢的東西,關掉就等於丟掉還沒存的配置。
- 拖曳視窗、開啟選單或檔案對話框造成的暫停不算「沒有回應」,不會產生檔案。
- 回報問題時,把當天那幾個檔一起附上最有幫助。裡面只有程式自己的執行位置與模組
  清單,沒有你的配置內容。
- 這些檔案和紀錄檔一樣保留 30 天,之後由程式自己清掉。
